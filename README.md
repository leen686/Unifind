# UniFind — University Lost & Found Platform

A full-stack web application designed to simplify how university students report, search for, and manage lost-and-found items.

## Project Overview

UniFind is a collaborative academic project developed to provide King Saud University students with a centralized lost-and-found platform. Instead of relying on scattered social media posts or group chats, students can manage lost-and-found reports through a structured, accessible web interface.

## Key Features

- **User Authentication:** Account registration, login, and profile management.
- **Lost & Found Reporting:** Create, edit, and delete item reports with descriptions, locations, dates, and images.
- **Search & Filtering:** Search reports by keywords and categories, with sorting options.
- **Saved Reports:** Bookmark relevant reports for future reference.
- **Admin Dashboard:** Manage submitted reports through administrative interfaces.
- **Database Integration:** Store and retrieve application data using a relational database.

## Project Structure

- `index.php` — Landing page
- `register.php` and `login.php` — User authentication
- `reports.php` — Report browsing, search, and filtering
- `add-report.php` — Submit lost-and-found reports
- `my-reports.php` — Manage personal reports
- `saved.php` — Access bookmarked reports
- `admin-reports.php` — Administrative report management
- `unifind_db.sql` — Database schema
